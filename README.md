# AI for Workforce Readiness

Course site for **AI for Workforce Readiness**: lessons, agent labs, the final project, and grading info. Pages are plain static HTML served by a small Express server for local development.

## Local build

### Prerequisites

- [Node.js](https://nodejs.org/) (includes npm)

### Install and run locally

```bash
git clone https://github.com/Chart-Academy/ai-workforce-readiness.git
cd ai-workforce-readiness
npm install
npm start
```

Then open <http://localhost:8080>.

## Project layout

```
server.js        Express dev server
views/           HTML pages
public/          Static assets (CSS, JS, images, downloadable files)
AI_PROMPTS.md    Log of AI prompts used while building the project
```
