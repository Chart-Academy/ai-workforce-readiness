Setting Up Coding for Agents

Set up once, in about 15 minutes, to build job search agents with Claude Code. You'll connect Claude Code to your class API key, install Python, and save your work to GitHub, so you can pick up where you left off on any computer.

What you need

  • A class computer

    Claude Code, Git, and Python are already installed. Using your own? See Your own computer.

  • Your class Gmail

    The Google address you gave your instructor. Use it for GitHub too.

  • Your class API key

    Your instructor sends it to you privately. It comes with about $20 of Claude usage for the course.

  • A GitHub account

    Free. Make one at github.com/signup with your class Gmail if you don't have one.

The steps

  1. 1. Open a terminal
  2. 2. Sign in to GitHub
  3. 3. Your API key
  4. 4. Your class repo
  5. 5. Python packages
  6. 6. Start Claude Code
  7. Every class
  8. Another computer
  9. Your own computer
  10. If something goes wrong

My computer is a:

The steps below change to match.
1

Open a terminal

The terminal is a window where you type commands. You'll copy and paste every command on this page. Use the Copy button on each gray box.

  1. MacPress Command + Space, type Terminal, and press Return.
  2. WindowsClick Start, type PowerShell, and open Windows PowerShell. Don't choose "Run as administrator."
  3. To paste a command, click in the terminal and press Command + VCtrl + V. Then press ReturnEnter to run it.
2

Sign in to GitHub

GitHub stores your project online, so you can get to it from any computer. Git, Python, and the GitHub tool are already installed on class computers. You only need to sign in.

  1. No GitHub account yet? Go to github.com/signup and create a free one with your class Gmail. Pick a professional username, like firstname-lastname. Employers may see it.
  2. In the terminal, sign in: 
    gh auth login
    Answer the questions with your arrow keys and ReturnEnter: GitHub.com → HTTPS → Yes → Login with a web browser. Copy the 8-character code it shows, press ReturnEnter, paste the code in the browser, and click Authorize.
  3. Tell Git your name and email. Change the parts in quotes to yours, using the same email as your GitHub account: 
    git config --global user.name "Your Name"
git config --global user.email "you@gmail.com"

Check: gh auth status should say you're logged in.

3

Save your API key on your computer

Your API key lets Claude Code and your agents use your class budget. Save it once, and every new terminal window will have it.

Keep your key private. Never paste it into a chat with Claude, a document, a screenshot, an email, or any file in your project. If someone gets it, they can spend your budget. If you think it leaked, tell your instructor right away and they'll replace it.

  1. Find the key your instructor sent you. It starts with sk-ant-. Copy all of it.
  2. Run this command. When it asks, paste your key and press ReturnEnter. Nothing shows while you paste. That's normal. 
    read -s "K?Paste your API key, then press Return: " && echo "export ANTHROPIC_API_KEY=$K" >> ~/.zshrc && unset K && echo && echo "Saved."
    $k = Read-Host "Paste your API key, then press Enter"; [Environment]::SetEnvironmentVariable("ANTHROPIC_API_KEY", $k.Trim(), "User"); Remove-Variable k; "Saved."
  3. Close the terminal and open a new one. Then check that the key is there. This shows only the first few characters: 
    echo ${ANTHROPIC_API_KEY:0:10}
    $env:ANTHROPIC_API_KEY.Substring(0,10)

Check: you should see sk-ant-api. If you see nothing, run the save command above again, then open a new terminal.

4

Get your class repo

A repo (repository) is your project folder on GitHub. You'll make your own private copy of the class starter repo, Chart-Academy/jobsearch-starter, and download it to this computer.

  1. Type your first and last name. The commands below fill in your repo's name for you.

  2. First time only: make your private copy and download it into your Documents folder: 
    cd ~/Documents
gh repo create jobsearch-yourname --private --template Chart-Academy/jobsearch-starter --clone
    Already did this on another computer? Download your copy instead: 
    cd ~/Documents
gh repo clone jobsearch-yourname
  3. Go into your project folder: 
    cd jobsearch-yourname
  4. First time only: share your repo with your instructors so they can see your work. Run this inside your project folder: 
    gh api -X PUT "repos/{owner}/{repo}/collaborators/abchart" --silent
gh api -X PUT "repos/{owner}/{repo}/collaborators/waynel11" --silent
    Leave {owner} and {repo} exactly as they are. The GitHub tool fills them in for you.

Check: run ls (Mac) or dir (Windows). You should see CLAUDE.md, NOTES.md, and an agents folder. Your repo is also on GitHub at github.com/your-username/jobsearch-yourname.

Check sharing: this should list abchart and waynel11. They'll disappear from the list after your instructors accept.

gh api "repos/{owner}/{repo}/invitations" --jq ".[].invitee.login"
5

Install your Python packages

This creates a private Python space for your project, called .venv, and installs the tools your agents need. It stays on this computer and isn't saved to GitHub.

  1. Make sure you're in your repo folder from step 4. Then run: 
    python3 -m venv .venv && source .venv/bin/activate && pip install -r requirements.txt
    python -m venv .venv; .venv\Scripts\Activate.ps1; pip install -r requirements.txt
  2. WindowsIf you see "running scripts is disabled on this system," run this once, then run the line above again: 
    Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

Check: your terminal line now starts with (.venv).

6

Start Claude Code

  1. In your repo folder, run: 
    claude
  2. Claude Code asks: "Detected a custom API key in your environment. Do you want to use this API key?" Choose Yes.
  3. If it asks you to sign in or choose an account type instead, don't sign in with your personal Claude account. Type /logout, press ReturnEnter, and close the terminal. Then open a new terminal, go back to your repo folder, and run claude again.
  4. Type /status and press ReturnEnter. It should say you're using an API key. That means Claude Code is billing your class budget, not a personal account.
  5. Try it. Type:

    Ask Claude: "Read CLAUDE.md and NOTES.md and tell me what this project is. Then check that Python 3.12 is installed and the .venv is working."

That's it. Your computer is set up. 🎉

Every class

1. Start

Open a terminal and get your latest work from GitHub:

cd ~/Documents/jobsearch-yourname && git pull && source .venv/bin/activate && claude
cd ~\Documents\jobsearch-yourname; git pull; .venv\Scripts\Activate.ps1; claude

2. Build

Tell Claude what you want in plain English. Check what it builds before you trust it, and type /cost any time to see how much you've used.

3. Save to GitHub

Before you leave, every time:

Ask Claude: "Update NOTES.md with what we did today and what's next. Then commit and push my work to GitHub."

Why NOTES.md matters: Claude doesn't remember your conversations from one computer to another. Your repo does. Claude reads CLAUDE.md and NOTES.md at the start of every session, so keep them up to date and you can pick up on any computer.

Using a different class computer

On a class computer you haven't used before, do steps 1–6 again. Skip making a GitHub account, and in step 4 use the "Already did this on another computer?" command. Your work comes down from GitHub.

Class computers are shared. Before you leave, sign out of GitHub and remove your key so the next person can't use your work or your budget:

gh auth logout; sed -i '' '/ANTHROPIC_API_KEY/d' ~/.zshrc && echo "Signed out and key removed."
gh auth logout; [Environment]::SetEnvironmentVariable("ANTHROPIC_API_KEY", $null, "User"); "Signed out and key removed."

Using your own computer

Class computers come ready. On your own computer, install these first, then do steps 1–6.

InstallGit, the GitHub tool, Python 3.12, and Claude Code+
  1. MacGit: run this. If a window asks to install "command line developer tools," click Install. 
    xcode-select --install
  2. MacGitHub tool: go to cli.github.com, click Download for Mac, and open the installer.
  3. MacPython: go to python.org/downloads/macos, download the latest Python 3.12 installer, and open it. When it finishes, double-click Install Certificates.command in the Finder window that opens.
  4. WindowsGit, the GitHub tool, and Python, all at once. Click Yes or Agree if Windows asks: 
    winget install --id Git.Git -e; winget install --id GitHub.cli -e; winget install --id Python.Python.3.12 -e
  5. Claude Code: follow install Claude Code.
  6. Close the terminal, open a new one, and check that each one is there: 
    git --version; gh --version; python3 --version; claude --version
    git --version; gh --version; python --version; claude --version

If something goes wrong

Claude Code can usually fix setup problems for you. Paste the error and ask Claude: "I got this error. What does it mean, and how do I fix it?" Never paste your API key.

What you seeWhat to do
"command not found" or "is not recognized"Close the terminal and open a new one. If it still happens, the install didn't finish. Run that step again.
python is not recognized (Windows)Run the Python installer again, click Modify, and turn on Add Python to environment variables. Or use the winget command in Your own computer.
Claude Code asks you to log in, or /status doesn't say "API key"Your key isn't saved. Do the check in step 3. If it's empty, save the key again. Then type /logout in Claude Code and restart it.
"Invalid API key"The key was pasted wrong, or it was replaced. Save it again in step 3, copying the whole key with no spaces.
"Credit balance is too low" or a spending limit errorYou've used your class budget. Tell your instructor.
"running scripts is disabled" (Windows)See the fix in step 5.
git push is rejectedYour repo has newer work from another computer. Ask Claude: "Pull the latest changes from GitHub, fix any conflicts, then push."
The sharing command says "Not Found" or "none of the git remotes"You're not in your project folder. Run the cd command from step 4, then try again.
(.venv) is missing from your terminal lineRun the activate part of the "Start" command in Every class.

Ground rules for Claude Code

  • Keep your API key out of chats, files, screenshots, and GitHub. It's saved on your computer, and that's the only place it belongs.
  • Your budget is about $20 for the whole course. Check /cost, and start a fresh session with /clear when you switch tasks so you don't use extra.
  • Read what Claude wants to do before you approve it. You're responsible for anything it builds or changes.
  • Your agents can search and organize job listings, but you apply yourself. Never let an agent log in to a job site or apply for you.
  • Push to GitHub at the end of every class. If it isn't on GitHub, it isn't saved.

Stuck for more than 10 minutes? Ask your instructor. Setup problems are normal, and they're faster to fix together.
