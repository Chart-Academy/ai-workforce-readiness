Module 3 · Creating agents · Lesson 5

Creating Agents

An AI assistant with a job description: standing instructions, the information it needs, and the tools it can use.

Learning objectives

The learner will be able to:

  1. Explain what makes an agent different from a single chat with AI.
  2. Write agent instructions that include a goal, rules, inputs, and an output format.
  3. Give an agent the files or tools it needs, such as web search or a spreadsheet.
  4. Test an agent on three real tasks and revise its instructions based on the results.

The big idea

What makes an agent

  1. InstructionsIts job description, written once
  2. InformationFiles and facts it needs for the job
  3. ToolsWeb search, spreadsheets, calendars

A chat assistant starts fresh every time. An agent remembers its job and follows the same rules on every task.

The skill for today

Writing agent instructions

  1. GoalWhat is its job?
  2. RulesWhat must it always or never do?
  3. InputsWhat will you give it?
  4. OutputWhat should it hand back?

Example: shift planner

“Help me plan my work week around my shifts. Never book anything during my classes. Flag any overlaps. Ask before moving anything. I'll paste my shift schedule and my appointments. Give me a table with day, time, and what, then a list of conflicts.”

Equip it

Giving an agent files and tools

  • Files

    Your résumé, a job posting, an inventory sheet

  • Web search

    Current openings and facts. Check its sources.

  • Spreadsheet

    Keep records, sort, and total

  • Calendar

    Find open time and spot conflicts

Give it only what the job needs. The privacy rules from Lesson 2 still apply.

Make it reliable

Test it, fix it, test again

  1. TestRun it on a real task
  2. SpotFind what it got wrong
  3. FixAdd or change a rule
  4. RetestSame task. Is it better?

Problem

The job agent listed openings 2 hours away.

Fix the instructions

Add the rule: “Only list jobs I can reach in 30 minutes by bus from [my neighborhood].”
