Microsoft Word

Make documents that look professional, and use AI to draft and fix them faster.

Real-world problem

The safety notice

Before

SPRINGFIELD COMMUNITY REC CENTER Fall Safety Notice - Please Read!!! 1) REPORTING AN INJURY Put out a yellow wet floor sign… Emergancy 911

After

  • One font, clear headings
  • Real bullets and a real table
  • Typos fixed, wording easy to scan
  • Saved as a PDF to email to 40 staff

It goes up tomorrow. Rules and phone numbers can't change. Only the look and the wording can.

Neat and fast

Use styles, not hand formatting

  1. TitleThe name of the document
  2. Heading 1Each main section
  3. NormalRegular paragraphs
  4. ListSteps and bullet points

How

Select the text, then click a style on Home → Styles. Change a style once, and every heading that uses it updates.

Click Home → ¶ to show hidden spaces and tabs. Rows of dots mean someone lined things up by hand.

Line things up

Real lists and tables instead of spaces

Spaces (breaks when you edit)

Who Phone Manager (555) 014-2290 Facilities (555) 014-2275

Table (stays lined up)

WhoPhone
Manager on duty(555) 014-2290
Facilities(555) 014-2275

Select the lined-up text, then Insert → Table → Convert Text to Table.

Let AI help with the words

Draft, shorten, or reword

Ask

“Rewrite this safety notice so staff can read it in under a minute. Use short sentences and bullet points. Keep every rule, time, and phone number exactly the same.”

Where:

  • Copilot in Word, if your account has it
  • Or paste the text into your AI assistant

AI can quietly change a number or drop a rule. Compare every line with the original.

Stay in control

Track Changes and comments

  1. Turn it onReview → Track Changes
  2. Make or paste editsEvery change shows in color
  3. Accept or rejectOne change at a time, you decide
  • Add a comment to ask a question instead of guessing: Review → New Comment
  • Your supervisor can see exactly what changed and why

Before you print or send

A quick final check

  • Spelling

    Review → Spelling & Grammar

  • Read it out loud

    Review → Read Aloud catches missing words

  • Accessibility

    Review → Check Accessibility flags hard-to-read parts

  • Print preview

    File → Print shows page breaks

Save and share

Clear names and Portable Document Format (PDF) copies

Hard to find

Document1 (3) FINAL final.docx

Easy to find

Safety-Notice_2026-10-19.docx

  • Keep the Word file so you can edit it later
  • Email a PDF so the layout looks the same on every phone and computer: File → Save As → PDF
