Google Docs and Google Slides

Make documents and short presentations that look professional, and use AI to draft and fix them faster.

Real-world problem

The safety notice

Before

SPRINGFIELD COMMUNITY REC CENTER Fall Safety Notice - Please Read!!! 1) REPORTING AN INJURY Put out a yellow wet floor sign… Emergancy 911

After

  • One font, clear headings
  • Real bullets and a real table
  • Typos fixed, wording easy to scan
  • Shared as a PDF with 40 staff
  • Three slides for Monday's staff meeting

It goes up tomorrow. Rules and phone numbers can't change. Only the look and the wording can.

Get started

Open the file in Google Docs

  1. UploadGoogle Drive → New → File upload
  2. Open itDouble-click the file, then choose Open with → Google Docs
  3. ConvertFile → Save as Google Docs so every tool works

Rename it right away: click the file name at the top left. Safety-Notice_2026-10-19 beats Copy of notice (3).

Neat and fast

Use styles, not hand formatting

  1. TitleThe name of the document
  2. Heading 1Each main section
  3. Normal textRegular paragraphs
  4. ListSteps and bullet points

How

Select the text, then pick a style from the Normal text menu in the toolbar. To change every heading at once: fix one, then choose Format → Paragraph styles → Heading 1 → Update “Heading 1” to match.

Turn on View → Show non-printing characters. Rows of dots mean someone lined things up with spaces.

Line things up

Real lists and tables instead of spaces

Spaces (breaks when you edit)

Who Phone Manager (555) 014-2290 Facilities (555) 014-2275

Table (stays lined up)

WhoPhone
Manager on duty(555) 014-2290
Facilities(555) 014-2275

Insert → Table, pick the size, then type or paste each entry into its cell. Use Format → Bullets & numbering for lists.

Let AI help with the words

Draft, shorten, or reword

Ask

“Rewrite this safety notice so staff can read it in under a minute. Use short sentences and bullet points. Keep every rule, time, and phone number exactly the same.”

Where:

  • Gemini in Google Docs (“Help me write”), if your account has it
  • Or paste the text into your AI assistant

AI can quietly change a number or drop a rule. Compare every line with the original.

Stay in control

Suggesting mode and comments

  1. Turn it onTop right, switch Editing → Suggesting
  2. Make or paste editsEvery change shows in color
  3. Accept or rejectClick ✓ or ✕ on each one. You decide.
  • Ask a question instead of guessing: Insert → Comment
  • Your supervisor can see exactly what changed and why

Google Slides

Turn the notice into three slides

  • Start

    Google Drive → New → Google Slides, then pick a simple theme

  • One idea per slide

    Slide → Apply layout → Title and body. Title, top 3 rules, emergency contacts.

  • Fewer words

    Short phrases on the slide. Put what you'll say in the speaker notes below the slide.

Copy facts from your finished document, not from the AI's draft, so the rules and numbers match.

Before you share

A quick final check

  • Spelling

    Tools → Spelling and grammar

  • Read it out loud

    Reading aloud catches missing words

  • Check the outline

    View → Show outline lists your headings. Missing one? It isn't a heading yet.

  • Print preview

    File → Print shows page breaks

Save and share from Google Drive

Share links and Portable Document Format (PDF) copies

Risky

“Anyone with the link can edit”

Safer

“Anyone with the link can view”

  • Share a link: Share → General access → Anyone with the link → Viewer → Copy link
  • Make a PDF so the layout looks the same everywhere: File → Download → PDF Document (.pdf)
  • Google saves as you type. There's no Save button.
